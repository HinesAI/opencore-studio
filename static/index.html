    Specification: How Custom Repos & Profiles Work

    1. Kext Repository Requirements:

    • Must publish releases on GitHub or host zip archives with .kext bundles.
    • Kexts must provide standard Contents/Info.plist and binary in Contents/MacOS/.
    • Plugins must specify relative bundle paths (e.g. VirtualSMC.kext/Contents/PlugIns/SMCProcessor.kext).

    2. Hardware Profile JSON Schema:

    {
  "id": "my_cpu_profile",
  "name": "Human Friendly Name",
  "platform": "desktop|laptop|vm",
  "architecture": "Intel|AMD",
  "mandatorySsdt": [{"name": "SSDT-PLUG.aml", "reason": "..."}],
  "recommendedKexts": ["Lilu", "VirtualSMC"],
  "booterQuirks": {"DevirtualiseMmio": true, ...},
  "kernelQuirks": {"ProvideCurrentCpuInfo": true, ...},
  "recommendedBootArgs": "-v keepsyms=1 debug=0x100"
}
